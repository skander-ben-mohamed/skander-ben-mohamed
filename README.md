## 🚀 Key Engineering Projects

### 1. [3aweni] — Tunisian Home Services Marketplace
- **Architecture:** Two-sided distributed marketplace connecting clients with verified service providers.

- **Core Components:** Escrow-gated transaction flows, real-time mission chat, QR-validated arrivals, and automated pricing insights via OpenRouter AI.

- **Stack:** Flutter (Mobile), NestJS (API), Supabase & PostgreSQL (Data Layer), Next.js (Admin Dashboard).

### 2. [VisiInspect](https://github.com/skander-ben-mohamed/VisiInspect-Industrial-Visual-Defect-Detection-Platform) — Industrial Visual Defect Detection Platform
- **Architecture:** End-to-end computer vision pipeline for automated manufacturing quality control.

- **Performance & Optimization:** Fine-tuned ResNet-50 on MVTec AD reaching 97.7% accuracy (94.7% F1), exported to ONNX Runtime for high-throughput (~30 ms CPU inference), supplemented with Grad-CAM explainability heatmaps.

- **Stack:** PyTorch, ONNX, FastAPI, PostgreSQL, React, Docker, MLflow, GitHub Actions.

### 3. [DocuMind](https://github.com/skander-ben-mohamed/DocuMind) — Enterprise Document Search & RAG Engine
- **Architecture:** Full-stack retrieval-augmented generation platform designed for deep document parsing and semantic indexing.

- **Stack:** TypeScript, React, Python, FastAPI, BGE-M3 Embeddings, ChromaDB, Docker.
